# dsh-todo-completion-guard

[English](README.md) | 中文

建议性的回合结束守卫：当一个本已完成的回合即将结束、而其现行待办列表仍有未完成项时，向同一回合注入一条插件通知，提示模型完成并勾掉条目、围绕有意放弃重写列表、或明确说明列表保持开放的理由。它从不否决回合、从不出现在工具列表中、每回合至多提醒一次、绝不循环。

## 安装

```sh
dsh plugin add <仓库根>/plugin/dsh-todo-completion-guard
```

无配置项。守卫可能暴露的每个旋钮（提醒文案、每回合上限、豁免规则）都是建议性契约的正确性属性，不是部署选项。

## 行为

- 在 `agent/turn-stopping` 触发——完成的回合即将收口前的边界。
- 读取现行列表：当前回合计入的 `turn/start` 之后最近一次 `todo/write`（更早回合写的列表已被 todo 投影的清除规则清掉，不会被追提醒）。
- `pending` 与 `in_progress` 都算未完成；被遗忘的 `pending` 条目正是本守卫要兜的残留。
- 豁免：撞墙回合——若任一步以 `max-tokens` 结束，再强制一步大概率再次撞顶，守卫保持沉默。
- 每 agent 每回合一次：被引导后仍以开放列表结束的回合允许结束。完成、重写还是显式推迟，决定权在模型。
- 提醒是一条 `notice` 形态的上下文消息，source 为 `dsh-todo-completion-guard`，模型可见、可溯源、可从会话日志重建。
- 组合中没有 todo 工具（`todo_write`）时挂载无效：任何回合都不会写出该事件。
- 子代理列表按设计不可见——守卫读取每个 agent 自己的会话日志；子代理的未完成列表不会引导父代理。
