# Quno 设置改单页表单（2026-10-28）

把设置·Quno 从「页签 + 仪表盘式头部」改成与其他设置一致的单页表单；Quno 的个性留在对话，设置只做安静、明确的配置。

## 页面结构

- 标题 `Quno`（16/24/500）+ 一行说明（14/22）。
- 分组：**基本**（启用、检查间隔、时区）、**通知**（通知方式、安静时段、高级通知折叠）、**角色与模型**（名称、模型选择器、推理档位、角色描述、长期职责）、**感知来源**（名称/类型/一句摘要 + 编辑、接入来源）、**高级**（每轮事件/上下文/每日运行上限，默认折叠）、底部**主对话**普通行。
- 删除：内部页签、主对话状态 chip、打开/刷新按钮组、大标题与宣传副标题、状态计数、Sense 详情卡、设置内的暂停/恢复/探测/停用。
- 设置不再 import `SenseDetail`；运行态全部由右栏「动态 → Sense 详情」承接。

## 自动保存

- 开关/选择器：操作后立即保存。
- 数值/时间/时区/文本：失焦或 Enter 校验后保存；非法值不发 Remote、保留编辑内容并原地提示。
- 串行队列（`useRef(Promise)`），最小 patch：`updateConfig({ patch })` / `updateProfile(patch)`；不发整份配置。
- 分组内小字反馈：`保存中… / 已保存 / 保存失败：原因 + 重试`；失败保留草稿。
- 本地草稿为唯一编辑源，15 秒轮询不会覆盖正在编辑的字段。
- 主对话行：已绑定 → 打开；未绑定 → 创建并打开；异常 → 显示清晰错误（`ensureMain` 抛错，不静默新建）。

## 模型选择器

- 优先读 `remote.session.modelCatalog()` 的 `groups`（与 composer 同源）；失败再回退 `remote.llm`；都不可用时退化为 provider/model 手填。
- 推理档位为 `默认 / low / medium / high`，保留自定义值。
- 时区用 `datalist` 提供常用 IANA 区，同时允许手填。
