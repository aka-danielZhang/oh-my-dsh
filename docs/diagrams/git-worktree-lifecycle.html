SEQUENCE · GIT WORKTREE CONVENTION

Git worktree 生命周期：创建 → 开发 → 合并 → 清理

同级目录 <repo>-<topic> 与 feature/<topic> 分支一一对应：创建时 git 登记簿记并独占 checkout；开发与提交与主仓互不干扰；合并后 remove + prune 收尾，有未提交改动时 git 会拦你一次。

簿记（.git/worktrees/<name>/）是 git 自动维护的内部状态——一切对账都经 git worktree list / remove / prune，绝不直接编辑或删除其中文件。跨 worktree 的移动只走 git（分支 / 合并），不互拷文件。本图为通用规范示意，可随 AGENTS.md 的「Git worktree 约定」小节一起搬运到其他仓库。
