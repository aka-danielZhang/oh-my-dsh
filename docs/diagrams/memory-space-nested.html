记忆空间：范围、状态与视图

范围（scope）决定一条记忆跟着谁走，状态（status）决定它现在算不算数，视图（views/）是系统按范围生成好的只读摘要。本图按真实目录结构绘制：一条记忆就是一个带 frontmatter 的 .md 文件。

召回侧：每个新会话的常驻记忆胶囊（capsule）由 context 行从核心视图同源筛选——workspace 优先、importance 排序、8KB 预算内确定性截断；视图给人看，胶囊给模型看，准入条件相同（pinned · active · normal）。提取→入库→召回的完整调用时序见 memory-extraction-sequence.html。
